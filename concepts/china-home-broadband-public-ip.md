# 国内家用宽带公网 IP 现状（2026）

## 一句话结论

**个人家用宽带普遍没有独立公网IPv4；以移动最严格，基本不免费给。**

## 现状

### 默认情况
- 家用宽带默认：**CGNAT（运营商级NAT）大内网IP**（10/100/172开头），非独立公网IP
- 多户共享一个公网IP，无法从外网直接访问

### 运营商差异
| 运营商 | 免费公网IPv4 | 备注 |
|--------|-------------|------|
| **电信** | 部分地区可免费申请 | 动态公网IP（重启/断线会换IP），80/443端口常封 |
| **联通** | 部分地区可免费申请 | 同电信，部分地区更宽松 |
| **移动** | **几乎不给个人免费开** | 只推企业方案，免费也不给 |

### 静态公网IP（企业专线）
- 必须办**互联网专线/企业宽带**，**按月收费**
- 参考价：**100M约100-200元/月**，年费一千多，含1个固定IP
- 需签协议、备案，个人难办

## 替代方案（免费/低成本）

### 1. Cloudflare Tunnel（推荐）
- **不用公网IP、不用端口映射，永久免费**
- 外网通过 Cloudflare 全球节点→加密隧道→访问本地服务
- 适合飞书/微信机器人回调、个人工具站
- [[cloudflare-tunnel]] 详见相关概念页

### 2. IPv6
- 移动家用大多送**免费IPv6公网地址**
- 可配合DDNS（动态DNS）使用固定域名
- ⚠️ 飞书/微信等回调对IPv6支持一般
