# 域名基础知识

## 域名 vs 商标

| 维度 | 域名 | 商标 |
|------|------|------|
| 本质 | 互联网门牌号（定位网站） | 品牌法律身份证（防混淆） |
| 获取方式 | 先到先得，交钱买使用权 | 国家审核注册 |
| 唯一性 | 全球唯一（同后缀下） | 按行业分类保护 |
| 地域性 | 全球通用 | 有地域性（中国商标只在中国有效） |

域名是**线上地址+品牌名**，商标是**法律专属权**；能互相配合，但不能替代。

## 域名管理组织

### ICANN（全球总管）
- 性质：非营利国际组织（1998年成立）
- 职责：管根域名系统（.com/.net/.cn等后缀）、授权注册商、定规则、解决域名抢注争议（UDRP）

### CNNIC（中国总管）
- 性质：国家官方机构
- 职责：运营.cn/.中国域名，要求实名注册，协调国内域名政策

### 注册商（阿里云/腾讯云/Namecheap 等）
- ICANN授权的代理商
- 负责查/注册/续费域名、提供DNS解析、收年费

## DNS 解析

**DNS 解析 = 把域名翻译成 IP 地址**

比喻：
- 域名 = 地址名字（幸福小区3栋502）
- IP = 真实的经纬度坐标
- DNS = 查地址本，把名字变成坐标

流程：输入 `baidu.com` → 问DNS服务器 → 返回IP `223.94.207.172` → 浏览器连该IP

## 顶级域名（TLD）

### 分类
| 类型 | 示例 | 特点 |
|------|------|------|
| 通用顶级 | .com | 最通用最老牌，全球最值钱 |
| 国家顶级 | .cn | 中国专属，需实名认证，国内访问快 |
| 通用备选 | .net / .org | 早年分类，现在通用 |
| 新顶级 | .xyz / .top / .vip / .shop / .cloud / .icu / .app | ICANN后来放开，便宜好注册 |
| 国家/地区 | .hk / .us / .jp / .uk / .io | 各地区管理 |

### 核心原则
- **后缀不同，地位不同，但功能一模一样**
- 越短、越老牌、越通用 → 越贵、越值钱
- 奇怪后缀 → 便宜、好注册、适合测试

## 域名持有期限与续费

- 首次注册：**1～10年**（ICANN上限）
- 续费：每次**1～10年**，总有效期不超10年
- **本质是按年租用，不是永久购买**

### 到期三阶段
1. **宽限期（0-30天）**：正常价格续费，解析可能停但能恢复
2. **赎回期（约30天）**：还能拿回，要付高额赎回费（几百上千元）
3. **删除期（约5天）→ 释放**：彻底没了，任何人都可重新注册

### 价格参考（2026年）
- `.com`：注册60-90元/年，续费80-120元/年
- `.cn`：注册30-50元/年，续费35-50元/年
- `.xyz/.top`：首年几块钱，续费20-30元/年

## 域名所有权

- 域名不是"买到永久"，是**按年租用**
- 但只要**不停续费、不违法**，就**一直拥有独家使用权**
- 别人想拿，只能花钱买，或等忘记续费
- **域名和IP是解绑的**：IP会变、服务器会换，但域名可以跟着走

## 优质域名（.com / .cn）的好处

### 对搜索排名几乎没影响
搜索引擎（百度/谷歌）**不因为.com就多给排名**，也不因.xyz就看不起。真正影响排名的是内容质量、更新频率、访问速度。

### .com 的真正优势
1. **好记、可信、显得正规** — 普通人只认.com
2. **全球通用，不会被屏蔽** — 奇怪后缀可能被微信/飞书误判
3. **保值，以后能卖钱** — 好的.com越久越值钱

### .cn 的国内优势
- 国内访问速度略快
- 备案通过率更高、审核更友好
- 微信/QQ/飞书/小程序不容易拦截
- 政策风险最低

### 结论
- **同名字前提下，.com永远比.cn贵、更值钱**
- 普通用途（个人工具、机器人回调）→ 便宜后缀就够用
- 品牌商业用途 → .com 最好

## 域名更换IP
**完全可以，随便换。** 域名所有权不受IP变更影响，去域名后台改DNS解析记录即可，几分钟生效。
