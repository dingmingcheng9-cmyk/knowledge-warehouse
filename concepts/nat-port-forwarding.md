# NAT 与端口映射

## NAT（网络地址转换）——家用路由器默认模式

家里路由器本质上是 NAT，出厂默认就是这个模式：

- 所有人设备都是内网私网 IP（192.168.x.x）
- 上网时，路由器自动分配一个临时外网随机端口
- 用路由器本身的公网 IP 向外面网站发送数据
- 网站回复时，路由器查看之前记录的端口表，分发转回给请求的设备

**关键特性**：
- ✅ 你可以访问全世界外网
- ❌ 外网无法主动访问你的设备
- 端口临时随机，用完销毁
- 安全性最高

## 手动端口映射

人为固定指定端口：外网端口 → 转发到内网设备 IP + 固定端口。

**一旦做好端口映射**：
- 外网可以主动直接访问你的设备，双向互通
- 端口永久敞开，漏洞全部暴露

## 直白对比

| | NAT 自动分发（默认） | 手动端口映射 |
|--|---------------------|-------------|
| **方向** | 单向通行（你找外网） | 双向互通 |
| **外网访问你** | ❌ 无法触碰 | ✅ 能主动进来 |
| **端口** | 临时随机，用完销毁 | 永久敞开 |
| **安全性** | 最高 | 漏洞暴露 |

## 与 FRP 的关系

- **普通 FRP 中转模式**：双方都被 NAT 隔离，借用 VPS 公网服务器作为中间人搬运全部流量
- **FRP XTCP（P2P/打洞模式）**：VPS 只负责"牵线、交换地址、握手"，一旦打洞成功，双方直接连通，数据不再走 VPS

> **XTCP 理解**：TCP/HTTP/HTTPS = 中间人全程送货；XTCP = 媒人只牵线，之后你们私聊。
> **限制**：要求两边 NAT 类型支持，不是所有网络都能成功打洞。
