# 网络协议基础

网络协议就是**两台电脑互相聊天的统一语言规矩**。

## 最形象类比

- **网线/流量** = 马路
- **IP 地址** = 每家住户门牌
- **端口** = 房子里面每一间房间
- **各类协议** = 人与人说话的语言

一台电脑无数个端口，不同端口使用不同协议，分开各司其职交流。

## 层级关系

### 应用层（你看得见）
- **HTTP** 网页明文（端口 80）
- **HTTPS** 网页加密（端口 443）

### 传输层（底层搬运）
- **TCP** 稳定专用
- **UDP** 极速专用

### 最简公式
- HTTP = TCP + 网页明文（端口 80）
- HTTPS = TCP + 加密网页（端口 443）

## TCP（打电话）

TCP 是**可靠传输协议**，HTTP/HTTPS 全部建立在 TCP 上面运行。

**特点**：
- 三次握手建立连接（①我能听见吗 ②我可以，你能听见吗 ③我也可以）
- 发送数据必须确认收到
- 丢失数据包会自动重发
- 有序、不丢包、稳定

**常见 TCP 端口**：80、443、445、22、3389 通通属于 TCP。

**适用场景**：网站、远程桌面、文件共享、网盘、登录后台（需要安全完整）。

## UDP（发短信）

UDP 是**无连接传输协议**。

**特点**：
- 不用握手，直接发送
- 速度极致最快，会丢数据

**适用场景**：游戏、直播、视频、抖音、DNS（允许一点点丢包，要速度）。

## HTTP vs HTTPS

| 维度 | HTTP | HTTPS |
|------|------|-------|
| 端口 | 80 | 443 |
| 安全性 | 明文裸奔，中间人可截取篡改 | SSL 加密，防窃听防篡改 |
| 地址栏 | 没有小锁标志 | 金色小锁 |
| 速度 | 更快，不用加密运算 | 稍微慢一点，流量损耗更高 |

**选择口诀**：
- 内网（NAS、本地后台、局域网）→ **HTTP** 更快更省事
- 公网（外网穿透、手机登录）→ **必须 HTTPS**，否则账号被盗、浏览器拦截

> ⚠️ **重要误区**：HTTPS 不是只读的。HTTPS 只是加密运输通道，它本身不限制你能不能修改/删除/上传文件。能否修改取决于应用软件是否开放了写入权限（如宝塔面板、网盘后台都有写入接口）。

## 常见端口速查

| 端口 | 协议 | 用途 |
|------|------|------|
| 22 | SSH | 远程控制 |
| 80 | HTTP | 网页明文 |
| 443 | HTTPS | 网页加密 |
| 445 | SMB | Windows 文件共享 |
| 455 | SMB 相关 | 不常用，曾被标记为木马端口 |
| 1080 | SOCKS5 | 代理 |
| 3389 | RDP | 远程桌面 |
| 8080 | HTTP 替代 | 常用 HTTP 代理/WebDAV |

> **455 端口**：可用但属于"不常用+有风险"端口。曾被木马/后门使用（如 FatalConnections）。内网自用没问题，❌ 对外暴露不建议。查占用：`netstat -ano | findstr :455`
