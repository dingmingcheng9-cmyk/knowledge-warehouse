# Node.js 基础概念

> **来源**: [豆包 AI 对话](https://www.doubao.com/thread/w350ee782404117d6) · 2026-05-18 · AI 生成

## 核心定义

**Node.js = JavaScript 代码的解释执行器 + 运行平台**

- 基于 Chrome V8 引擎打造的**服务端 JavaScript 运行环境**
- 不是编程语言、不是软件 APP、不是框架——只是一个**代码运行平台**
- 把浏览器里的 JS 引擎搬出来，脱离浏览器在电脑/服务器上直接跑 JS

## 核心组成

1. **V8 引擎**（核心）—— 谷歌浏览器用来解析执行 JS 的引擎，Node 搬出来单独用，速度极快
2. **内置 API** —— 自带文件读写、网络请求、进程管理、数据库操作等后台功能
3. **NPM 包管理器** —— 全球最大开源代码库（自带"软件商店"），`npm install` 一键安装工具

## 与浏览器 JS 的区别

| 浏览器 JS | Node.js JS |
|-----------|------------|
| 只能操作网页（改文字、弹窗、监听点击） | 没有 DOM 功能 |
| 不能操作电脑文件、不能搭建服务器 | 专攻后台、电脑本地操作 |

## Node.js 能干什么

1. **后端开发**（最主流）—— 网站后台、API 接口、小程序后端、APP 服务端
2. **前端必备工具** —— 运行 Vue/React/uniapp 项目，打包压缩，启动本地开发服务器
3. **桌面软件开发** —— VS Code、钉钉电脑版、微信开发者工具、网易云桌面端都是 Node 写的
4. **脚本自动化** —— 批量改文件、爬取数据、自动填表、定时任务、办公自动化
5. 游戏服务端、物联网、小程序云开发
6. 搭建代理、本地服务、本地接口调试

## 优点

1. 前后端同一门语言（前端程序员不用学新语言就能写后台）
2. 非阻塞异步，处理高并发极强（适合直播、聊天、商城）
3. 轻量、启动快、部署简单
4. 生态超级庞大

## 安装后多出的命令

- `node` —— 运行 JS 代码
- `npm` —— 下载各类开发工具（NPM = Node 自带软件商店）

## 一句话总结

> 把浏览器里跑 JS 的引擎单独拿出来，变成可以在电脑和服务器上运行 JS 代码的平台，既能写前端项目，又能写网站后台。
