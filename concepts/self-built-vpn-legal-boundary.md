# 自建 VPN/内网穿透的法律边界

## 一句话核心

在中国，**个人私自搭建境内↔境外的任何加密/隧道通信通道均属违规**，无论用途（学习、传文件、回家内网），无论工具（WireGuard、FRP、SSH隧道、Nginx反向代理、Cloudflare Tunnel）。

## 判断公式（最简）

| 场景 | 定性 |
|------|------|
| 服务器在国内，用VPN/FRP做内网穿透 | ✅ 合法 |
| 服务器在境外，用任何工具搭私人跨境隧道 | ❌ 违规 |
| 正常上网走运营商官方国际出口 | ✅ 合法 |
| 私搭隧道绕开官方出口 | ❌ 违规 |

## 底层逻辑

### 运营商如何控制国际出口？

国内所有家庭宽带、手机流量、普通云服务器全部在**国内内网大网**里。国家只设少数几个官方国际出入口骨干节点，相当于整个中国只有有限几个"国门"通向国外互联网。

运营商在骨干网路由层面进行管控：
1. **路由黑洞**：大量境外网段在骨干网路由中被丢弃，普通公网IP无法出境
2. **国际出口带宽白名单**：只对正规持牌企业专线、高校科研、正规业务服务商放行
3. 普通浏览器能访问部分国外网站是因为国内有镜像/CDN缓存节点

### 为什么买海外轻量云合法但搭 VPN 违法？

- **买海外轻量云** = 远程租用一台国外电脑，走运营商正规国际出口 ✅ 合法
- **搭 VPN** = 自建加密隧道绕开监管信道 ❌ 违法

法律依据：《计算机信息网络国际联网管理暂行规定》第六条 — 任何单位和个人不得自行建立或者使用其他信道进行国际联网。

### 工具中立原则

法律不看具体工具，只看行为本质：
- WireGuard / OpenVPN / IPSec → VPN 协议
- FRP / Ngrok → 端口转发工具
- SSH 隧道 / Nginx 反代 / Cloudflare Tunnel → 隧道工具

**使用场景决定合法性**，不是工具本身。工具放国内做内网穿透 = 合法；工具放海外搭跨境隧道 = 违规。

## 合法方案

国内云服务器（阿里云/腾讯云轻量）做中转：
- 出国链路 → 全程国内流量，不跨境 ✅ 完全合规
- 适用场景：远程访问家里NAS/电脑/文件、居家办公
- 推荐工具：WireGuard（全联网段）、FRP（单端口映射）

## 个人合规跨境访问的现实

- 个人**无法**申请官方合法跨境 VPN（需企业法人、注册资金1000万、3名技术人员）
- 企业合规专线月费2000-5000元起
- 现实中的低风险方案：低配海外轻量云自建 WireGuard（20-40元/月），自用小流量学习查资料，**但法律定性仍是违规，只是现实风险很低**
