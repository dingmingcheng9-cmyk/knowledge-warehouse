# 软件安装包架构与格式

下载软件时遇到 x64/arm64/x86、.msi/.exe 等选项，这里是它们的关系。

## 架构版本

| 架构 | 说明 | 适用设备 |
|:---|:---|:---|
| **x64** | 64 位桌面端 | Intel/AMD 主流 CPU（联想小新、Wyse-5070 等），**最常用** |
| **arm64** | ARM 架构 | Surface Pro X、树莓派、手机芯片 |
| **x86** | 32 位桌面端 | 旧款低配置设备 |

- 所有架构都对应同一个操作系统（如 Windows 11）
- 选错架构版本无法运行

## 安装格式

| 格式 | 说明 | 适用场景 |
|:---|:---|:---|
| **.exe** | 通用可执行安装包 | 双击运行，兼容性强，个人用户日常使用 |
| **.msi** | 微软标准安装包 | 支持静默安装、批量部署、组策略分发，适合企业/自动化 |

- .msi 和 .exe 功能相同，只是打包/部署方式不同
- .msi 是企业友好的格式，.exe 是个人友好的格式

## 选择逻辑

1. 看**发布日期**：确认下载的是最新版本
2. 看**目标系统**：确保兼容自己的操作系统（如 Windows 11）
3. 看**CPU 架构**：选对 x64/arm64/x86
4. 选**安装格式**：个人用 .exe，企业部署用 .msi
