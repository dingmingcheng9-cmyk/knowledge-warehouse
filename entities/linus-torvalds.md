# 林纳斯·托瓦兹（Linus Torvalds）

**林纳斯·本迪克特·托瓦兹（Linus Benedict Torvalds）**，芬兰裔美国软件工程师，Linux 内核创始人和 Git 版本控制系统创建者。

## 关键事实

- **1991 年**：在芬兰赫尔辛基大学读书时发布 Linux 内核第一版
- **至今**：Linux 内核的总负责人、最终合并者（BDFL — Benevolent Dictator For Life）
- **2005 年**：创建 **Git**，现已成为全球最广泛使用的版本控制系统
- **净资产**：约 **5000 万美元**（主要来自 Red Hat、VA Linux 早期股票期权）

## 对世界的巨大贡献

- 全球 **90%+ 服务器**运行 Linux
- 全球 **100% 超级计算机**运行 Linux
- **Android**（全球最大移动操作系统）基于 Linux 内核
- 云计算、AI 大模型训练、物联网、车机系统底层均为 Linux
- Linux 开源模式直接启发了整个开源运动

## 名言名场面

- **2012 年**：在芬兰阿尔托大学公开骂英伟达"NVIDIA, FUCK YOU"并竖中指，原因是英伟达 Linux 驱动极差
- **价值观**：技术实用主义者，反对过度理想主义，坚持"技术够用就行"

## 财富 vs 贡献

用金钱衡量：他不是最富有的人（5000 万美元 vs 马斯克/贝佐斯千亿级）
用人类文明贡献衡量：**数字时代的上帝级缔造者**——全球几十亿人的生活、工作、娱乐，都在他写的代码之上运行。
