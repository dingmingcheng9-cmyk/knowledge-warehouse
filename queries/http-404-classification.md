# HTTP 404 错误分类与排查思路

404 本质：**服务器找到了，但找不到你要的那个页面/资源**。

## 三大类原因

### 一、客户端输入错误（最常见）

| 原因 | 示例 |
|------|------|
| 网址拼写错误 | `index.html` 写成 `index.htm` |
| 路径层级错误 | 访问了不存在的目录路径 |
| 旧链接过期 | 收藏的旧网址，页面已删除 |

### 二、服务器/网站配置问题

1. **文件被删除/改名/移动** — 旧地址直接 404
2. **站点根目录配置错** — Nginx/Apache 的网站根目录不对
3. **路由规则缺失（前后端项目）** — Vue/React SPA 没配伪静态路由，刷新直接 404
4. **端口/反向代理配置错** — 代理转发到不存在的服务路径

### 三、权限/访问控制类 404

1. **无权限伪装 404** — 为安全不提示 403，伪装成 404（防目录扫描）
2. **IP 被拦截/地域限制** — 屏蔽后抛 404 不暴露拒绝原因

## 快速排查思路

```
1. 检查网址有没有输错
2. 网站首页能不能打开？
   ├→ 首页能开、内页 404 = 路径/文件问题
   └→ 首页也 404 = 站点配置/根目录/端口问题
3. 别人能打开你打不开 = 你的 IP/网络被限制
```

## 与服务部署相关的 404 场景

- 容器端口映射错 → 访问 404
- Nginx 反向代理路径写错 → 404
- Heremus 网关路由地址输错 → 404
- 域名解析好了但网站没绑定站点 → 404
