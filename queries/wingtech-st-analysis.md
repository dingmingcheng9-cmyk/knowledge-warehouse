# 闻泰科技（*ST 闻泰）警告分析

## 背景

闻泰科技（Wingtech）是中国最大的 ODM（原始设计制造）手机方案商，2019 年以约 300 亿人民币收购荷兰安世半导体（Nexperia），成为全球最大的车规功率半导体厂商之一。

2026 年被实施退市风险警示（*ST），原因极为特殊。

## 被 *ST 的唯一直接原因：审计非标

闻泰被 *ST **不是因为经营烂了或财务造假**，而是：
- 会计师对年报出具**无法表示意见**
- 原因：闻泰海外资产（荷兰安世）被荷兰政府以"国家安全"为由夺走控制权，会计师无法核实这部分资产的真实价值

上交所规则：无法表示意见 → 自动触发退市风险警示

## 核心事件：荷兰政府夺权

- **2019 年**：荷兰政府批准闻泰收购安世半导体（100% 合规收购）
- **2025-2026 年**：荷兰以"国家安全"为由，实际控制海外安世（荷兰）运营权
- 结果：闻泰失去海外安世控制权，**资产估值砍半**

## 关键分歧：中国安世 vs 荷兰安世

- **中国安世**（东莞、上海、江阴）：承担原安世全球 **70% 封测产能**，正常满产运行
- **荷兰安世**：主要持有知识产权 + 海外晶圆厂 + 品牌，日常运营已空心化
- 中国安世使用的知识产权：荷兰曾同意授权，但夺权后法律地位复杂

## 还能不能活？

**有救，大概率能活下来：**
1. 中国安世还在正常赚钱（车规功率器件国内稀缺）
2. ODM 主业务没有烂，仍在盈利
3. 国资委背景，拥有中国大陆+马来西亚+新加坡供应链
4. 港股上市传闻 + 国内政策支持

**风险：**
1. 商誉严重减记 → 贷款额度缩小 → 资金压力大
2. 海外市场品牌和法律纠纷
3. 如果退市，融资渠道会收窄
