## 455端口一般可用吗

先把关键结论说清楚：455 端口本身是可用的，但属于 "不常用 + 有风险" 的端口，普通家庭 / 办公环境默认不用，也建议不要对外开放。

### 1. 455 是什么端口
- **TCP 455**：IANA 注册给 Microsoft-DS（SMB / 域服务），和 445 端口（SMB 文件共享）同属一类。
- **UDP 455**：也用于 SMB 文件共享相关。
- **现实中**：Windows 默认用 445，基本不用 455；455 更多见于老旧系统、特殊 NAS、或被恶意软件 / 木马使用。

### 2. 能不能用？
- **技术上**：可以用，属于 1024–49151 注册端口，你自己的程序完全可以绑定 455（TCP/UDP），只要没被占用。
- **默认占用情况**：Windows 10/11、服务器默认不监听 455，所以一般是空闲可用的。

### 3. 风险（重点）
- 455 曾被标记为木马 / 后门常用端口（如 FatalConnections）。
- 和 445 一样，属于 SMB 高危端口，外网开放容易被勒索病毒、扫描器盯上。
- 企业 / 机房防火墙通常会封禁 455（和 445、135、137、138、139 一起）。

### 4. 建议
- ✅ **内网自用程序**：可以用 455，没问题。
- ❌ **对外网暴露**：不要用 455，尽量换别的端口（比如 8080、9000 等）。
- 查本机是否占用：`netstat -ano | findstr :455`

**一句话总结**：455 端口空闲、能用，但不安全，不建议对外使用。

## HTTP 和 HTTPS 最简单大白话区别

### 1、端口不一样（最直观）
1. HTTP：端口 **80**
2. HTTPS：端口 **443**

### 2、安全性本质
1. **HTTP 明文传输**：所有数据裸奔，账号、密码、浏览记录全部看得见，中间人可以截取、篡改数据，没有加密。
2. **HTTPS 加密传输**：自带 SSL 加密，数据打包上锁，别人抓取到也是乱码，防窃听、防篡改。

### 3、使用差别
- HTTP：网页地址没有小锁标志，现在大部分网站淘汰
- HTTPS：地址栏金色小锁，现在所有官网、购物、小程序全部必须用

### 4、速度 & 功耗
- HTTP：更快、占用网速低、服务器耗电小，不用加密运算
- HTTPS：需要加密解密，稍微慢一点，流量损耗更高

### 5、内网外网怎么选
- **家里内网、本地后台、NAS、局域网**：完全可以用 HTTP，没必要 https，速度更快，省事
- **公网访问、外网穿透、手机外面登录**：必须 HTTPS，不然账号容易被盗，浏览器还会拦截打不开

### 6 补充你刚才问的端口
你之前看的 445、455 是文件共享端口，上网浏览就只用 80 (HTTP) 443 (HTTPS)

## 全网最好理解四层网络关系

### 1、TCP 是什么
TCP 是底层运输协议。HTTP、HTTPS 全部都是建立在 TCP 上面运行的。

### 2、两大传输核心协议
1. **TCP 可靠传输（打电话）**
   - 三次握手建立连接
   - 发送数据必须确认收到
   - 丢失数据包会自动重发
   - 有序、不丢包、稳定
   - 80、443、445、22、3389 通通属于 TCP

2. **UDP 无连接传输（发短信）**
   - 不用握手，直接乱发
   - 速度极致最快，会丢数据
   - 游戏、直播、视频、抖音、DNS 全部用 UDP

### 3 层级从上到下
1. **应用层（你看得见）**：HTTP 网页明文 / HTTPS 网页加密
2. **传输层（底层搬运）**：TCP 稳定专用 / UDP 极速专用

### 4 最简单关系
- HTTP = TCP + 网页明文，端口 80
- HTTPS = TCP + 加密网页，端口 443

### 5 日常所有端口分类
- **TCP**：网站、远程桌面、文件共享、网盘、登录后台（需要安全完整）
- **UDP**：看电视、打游戏、语音通话（允许一点点丢包，要速度）

### 6 三次握手大白话
1. 我能听见吗
2. 我可以，你能听见吗
3. 我也可以
连接成功＝TCP
UDP 直接一句话直接发送，不问对方有没有收到

## 协议本质 — 大白话理解

1. 所有**协议**，本质就是两台电脑互相聊天的统一语言规矩。
2. **TCP**＝沟通基础规矩：规定两台电脑怎么连上对方，先打招呼、确认连通，是底层对话框架。
3. **HTTP**＝聊天文字格式：连上之后，网页用的说话话术，直白裸文字。
4. **HTTPS**＝加密版聊天话术：一模一样的说话内容，只不过全部上锁加密。
5. **UDP**：不需要打招呼连线，直接丢消息，只求速度。

**最形象例子**：
- 网线、流量＝马路
- IP 地址＝每家住户门牌
- 端口＝房子里面每一间房间
- 各类协议＝人与人说话的语言

## WebDAV 协议

WebDAV = 带"读写权限"的 HTTP，专门用来通过网络管理文件（上传/下载/改文件名/建目录/锁文件）。
全称：Web Distributed Authoring and Versioning。

### 与 HTTP/HTTPS 关系
- 底层：TCP
- 端口：HTTP 80 / HTTPS 443（推荐加密）
- 本质：HTTP 的扩展。普通 HTTP 只能"看"（GET），WebDAV 多了 PUT/DELETE/MKCOL/COPY/MOVE/PROPFIND 等"写"动作。
- 类比：HTTP = 只能浏览网页，WebDAV = 能把网页服务器当网络硬盘用。

### 核心用途
- ✅ 像本地文件夹一样挂载远程 NAS/服务器/网盘
- ✅ 跨平台：Windows、macOS、Linux、手机都能连
- ✅ 多用户协作：文件锁定（防止两人同时改一个文件）
- ✅ 私有云、照片备份、笔记同步、NAS 外网访问常用

### 协议对比
| 协议 | 端口 | 特点 |
|------|------|------|
| HTTP | 80 | 网页浏览，只读，明文 |
| HTTPS | 443 | 网页浏览，只读，加密 |
| **WebDAV** | 80/443 | 文件读写，可加密，基于 HTTP |
| SMB | 445 | Windows 局域网文件共享，不跨公网 |
| FTP | 21 | 老牌文件传输，明文，防火墙容易挡 |

**简单选型**：
- 内网 Windows 共享 → SMB（445）
- 外网/跨平台/安全 → WebDAV over HTTPS（443）
- 旧设备/简单传文件 → FTP

### 安全要点
- ❌ 不要裸奔用 HTTP 公网暴露：账号密码明文传输
- ✅ 公网必须 HTTPS + 强密码 + 限制 IP
- ✅ 内网用 HTTP 没问题，速度快、省事

## 网络 IP 类型一次性分清

### 1. WLAN IP（本机内网地址）
就是你手机/电脑在自家路由器里面的门牌号码。只可以家里 wifi 局域网里面互通。
- 格式一般：192.168.x.x
- 特点：所有人家里全部都是 192 开头；外网看不见；用来局域网互通、文件共享、webdav、端口转发

### 2. 网关 IP（路由器地址）
一般末尾是 .1。整个网络的大门，所有设备上网全部经过它，进路由器后台就是输这个。

### 3. 公网 IP / 外网 IP
你整栋房子对外总的地址。运营商分配，全世界互联网都可以访问。
- 每一户宽带只有一个外网 IP，家里所有手机电脑共用同一个外网 IP

### 4. 端口原理结合
- WLAN 内网 IP + 端口＝房子里面房间，专门局域网设备互相通讯 TCP 协议
- 外网 IP + 端口＝外面可以走进你家里

**完整链路**：网线宽带→外网 IP→路由器网关→本机 WLAN 内网 IP→各个端口→TCP/UDP 传输→HTTP/HTTPS/WEBDAV/SMB 协议

## HTTP / Socks5 代理

都是代理节点类型，用来翻墙、换 IP、隐藏本机地址。

### HTTP 代理
- 只负责网页、浏览器、APP 网络
- 端口一般：8080
- 优点：延迟低、最简单
- 缺点：不支持游戏、软件全局、聊天工具，加密弱

### Socks5 代理（最常用）
- 全能全局代理：浏览器、游戏、模拟器、所有软件都能用
- 端口一般：1080
- 加密更好、隐藏 IP 更彻底、稳定性最强
- 日常使用优先选 socks5

**简单区别**：HTTP 只能上网页临时用，Socks5 全部软件通用主流首选。

## FRP + SMB + 内网穿透综合解析

完整链路：NAS 家里内网(192.168.31.187:445) → FRP 客户端 → FRP 公网服务器(124.221.132.29:44500) → 你的电脑(10.63.x.x)

FRP 客户端↔FRP 服务器：FRP 自定义二进制协议，控制面 7000 端口，数据面用指定端口。
隧道建立后，里面跑的流量是纯 SMB 协议，FRP 只是"管道"，不改数据。

### 问题诊断
SMB 走裸 TCP 连接，不支持 HTTP/SOCKS5 代理。电脑开了代理环境时，SMB 无法走代理转发导致连接失败。

### 解决方案（按优先级）
1. **临时关闭代理**：最快验证
2. **全局 TCP 代理工具**：Clash for Windows「全局模式」/ ClashX Pro「增强模式」
3. **换思路，不用 SMB 穿透**：WebDAV（FRP 穿透 8080）、SFTP（穿透 22）、远程桌面

### 安全提醒
公网直接暴露 SMB 端口非常危险，建议：
- 给 FRP 加上强密码和 TLS 加密
- 公网服务器上用防火墙限制 IP 访问
- 优先用替代方案

## SSH 隧道

SSH 隧道就是用 SSH 协议，给其他 TCP 连接套上一层加密通道。

### 三种模式

**1. 本地端口转发（最常用）**
把远程服务器的端口映射到你本地电脑的一个端口上。
```bash
ssh -L 本地端口:目标地址:目标端口 远程用户@远程服务器
```
对应 SMB 场景：
```bash
ssh -L 44500:192.168.31.187:445 root@124.221.132.29
```

**2. 远程端口转发（反向隧道，内网穿透）**
把本地内网的端口映射到远程服务器上。
```bash
ssh -R 远程端口:本地地址:本地端口 远程用户@远程服务器
```

**3. 动态端口转发（SOCKS5 代理）**
在本地创建一个 SOCKS5 代理，所有流量通过 SSH 隧道出去。
```bash
ssh -D 1080 远程用户@远程服务器
```

### SSH vs FRP

| 特性 | FRP 隧道 | SSH 隧道 |
|------|----------|----------|
| 加密 | 可选（默认明文，可开 TLS） | 默认全程加密 |
| 配置难度 | 要装 FRP 客户端+服务端 | 只要有 SSH 就能用，一条命令搞定 |
| 适用场景 | 长期、多端口的内网穿透 | 临时、安全的端口转发 |

## HTTPS 不是只读的（常见误区）

HTTPS 只是运输通道，只管数据加密传送。它不限制能不能删除、修改、写入、上传。

- HTTP = 普通货车
- HTTPS = 密封防弹货车
- 货车只管运东西，能不能删东西是车内软件说了算

**为什么普通网页只能看不能改**？因为网站开发者只做了读取功能，没有开放写入权限。

**为什么宝塔、后台、网盘可以改文件**？因为后台面板自带写入权限接口，操作命令打包成 HTTPS 加密数据发出，服务器执行。

### 三种协议本质区别
1. **HTTP/HTTPS**：网页后台、宝塔、网站控制面板。可读、可改、可上传、可删除。
2. **SOCKS5**：纯全局 TCP 通道，万能中转。
3. **SSH 隧道**：最高级加密管道，远程改主机、修改系统文件。

## FRP XTCP（P2P/点对点）模式

普通 FRP（TCP/HTTP/HTTPS）：所有流量经过 VPS 中转。
XTCP（P2P）：VPS 只负责帮两边"牵线、交换地址、握手"，一旦打洞成功，双方直接连通，数据不再走 VPS。

**工作步骤**：
1. 两边都跑 frpc：家里（服务端）、你电脑（访问端）
2. 都连上公网 VPS 的 frps，上报自己的公网 IP/端口
3. frps 把双方地址互换，让你们互相"打洞"
4. 打通后 VPS 只留控制连接，不转发数据

**简单记**：TCP/HTTP/HTTPS = 中间人全程送货；XTCP = 媒人只牵线，之后你们私聊。
**限制**：要求两边 NAT 类型支持（不是所有网络都能成功打洞）。

## NAT vs 端口映射

### 1. 家里路由器本质：NAT 端口分发
默认出厂所有路由器都是 NAT（网络地址转换）模式：
- 所有人设备都是内网私网 IP（192.168.x.x）
- 上网时路由器自动分配临时外网随机端口
- 只能你主动去找外网别人，外网无法主动来找你

### 2. 手动端口映射
人为固定指定端口：外网端口 → 转发到电脑 IP + 固定端口。
一旦做好端口映射，外网就可以主动直接访问你的设备。

### 3. 直白对比
| | NAT 自动分发 | 手动端口映射 |
|--|-------------|-------------|
| 方向 | 单向通行 | 双向互通 |
| 外网访问 | 无法触碰你设备 | 能主动进来穿透 |
| 端口 | 临时随机，用完销毁 | 永久敞开 |
| 安全性 | 最高 | 漏洞全部暴露 |

### 4. FRP 原理 vs 打洞
- 普通 FRP 中转：双方都被 NAT 隔离，借 VPS 搬运流量
- P2P 打洞（XTCP）：服务器只交换端口记录表，两台设备绕过路由器分发直连
