**Debian 是一个完全自由、社区驱动的 Linux 发行版**，常被称为“**Linux 发行版之母**”。简单说：**Linus 写了内核（Linux），Debian 把内核 + 所有工具 + 软件包，打包成一个完整、能直接装的操作系统**。



### 一、基本信息
- **全称**：Debian GNU/Linux（强调 GNU 自由软件工具 + Linux 内核）
- **诞生**：1993 年，由 Ian Murdock 创立，名字来自他和妻子 Debra 的组合
- **理念**：**100% 自由软件**，社区完全志愿者运营，非商业公司控制

### 二、它和 Linux 的关系（关键）
- **Linux = 内核**（Linus 写的，管硬件、进程、内存）
- **Debian = 完整操作系统**（内核 + 命令行工具 + 库 + 软件包 + 安装程序 + 包管理器）
- 打个比方：
  - **Linux 是发动机**
  - **Debian 是整辆汽车**（发动机 + 车身 + 内饰 + 各种配件）

### 三、为什么它地位极高（“发行版之母”）
- **最古老、最稳定**：30 年历史，稳定版（Stable）经过极其严格测试，服务器首选
- **衍生无数发行版**：
  - **Ubuntu**（最流行桌面）→ 基于 Debian
  - **Kali Linux**（黑客/渗透测试）→ 基于 Debian
  - **Raspbian**（树莓派）→ 基于 Debian
  - 全球 **120+ 活跃发行版** 直接基于 Debian
- **包管理标准**：`.deb` 格式 + `apt` 命令，成为 Linux 生态最主流的软件安装方式

### 四、核心特点
- **极致稳定**：Stable 版更新保守，安全可靠，适合服务器、长期运行设备
- **海量软件**：官方仓库 **6万+ 软件包**，一键安装，几乎无所不包
- **完全自由**：无广告、无捆绑、不收集隐私，代码全公开可审计
- **多架构**：支持 x86、ARM、RISC-V 等几乎所有 CPU，从服务器到树莓派都能跑

### 五、一句话总结
**Linus 创造了 Linux 内核，Debian 把内核变成了真正可用、稳定、自由的操作系统，并养育了整个 Linux 生态。**
